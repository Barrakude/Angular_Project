# Angular_Project

## Descrizione

Questo progetto è una web app sviluppata con Angular che permette la gestione di una lista di task. Include funzionalità di ricerca, filtro, paginazione, modifica e cancellazione dei task. La struttura segue le best practice Angular, con suddivisione in moduli funzionali e shared.

## Struttura del progetto

- **src/app/features/**: contiene i moduli funzionali (es. task-list)
- **src/app/shared/**: contiene servizi, interfacce e pipe riutilizzabili
- **src/environments/**: variabili d'ambiente per sviluppo e produzione

## Funzionalità principali

- Visualizzazione task con paginazione
- Ricerca e filtro per titolo, descrizione e stato
- Modifica e cancellazione task
- UI responsive con Bootstrap

## Avvio del progetto

### 1. Installazione delle dipendenze

```bash
npm install
```

### 2. Avvio del backend (json-server)

Assicurati che il backend sia attivo sulla porta 3000. Se usi json-server:

```bash
npm run dev
```

oppure

```bash
json-server --watch db.json --port 3000
```

### 3. Avvio dell'app Angular

```bash
ng serve
```

L'app sarà disponibile su [http://localhost:4200](http://localhost:4200).

## Script utili

- `npm run dev` : Avvia il backend json-server
- `ng serve` : Avvia il frontend Angular in modalità sviluppo

## Test

Puoi aggiungere test unitari e di integrazione usando Jasmine/Karma (default Angular). Per eseguire i test:

```bash
ng test
```

## Note

- Assicurati che il backend sia avviato prima di lanciare l'app Angular.
- Modifica la configurazione dell'API in `src/environments/environment.ts` se necessario.
